# Dataset Source

## Brazilian E-Commerce Public Dataset by Olist

Source:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Provider: Olist
Publication platform: Kaggle
License: CC BY-NC-SA 4.0

Description:
Public anonymized Brazilian e-commerce transaction
data covering approximately 100,000 orders from
2016 to 2018.

The original CSV files are not included in this
GitHub repository.
